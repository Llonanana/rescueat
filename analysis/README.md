# 第二組專題：營養資料前處理與推薦系統

已用**真實官方資料**跑完：食藥署食品營養成分資料集（2,213 項食材 × 104 個分析項，共 230,152 筆）＋ 國健署 DRIs 第八版總表（111 年公告）＋ 台師大六大類份量。

## 一鍵執行

```bash
pip install pandas
python run_pipeline.py data/raw/20_2.csv
```
（`20_2.csv` 就是從 data.gov.tw 下載的食品營養成分資料集，原檔太大沒放進壓縮檔；放進 `data/raw/` 即可重跑）

## 三個階段做了什麼

### 一、資料蒐集
| 資料 | 系統用途 |
|---|---|
| 食藥署 食品營養成分資料集 | 每 100 g 營養素，算餐點營養 |
| 國健署 DRIs **第八版**總表（111 年） | 16 歲以上 10 組（性別×年齡）的熱量、膳食纖維（依 4 種活動量）、蛋白質與 20 種維生素礦物質，以及鈉上限 → `data/reference/dris_adult.csv` |
| 台師大 成人建議攝取量 | 六大類每日份數 → 均衡判斷規則（此頁只有熱量與六大類份數，沒有各營養素數值） |

### 二、資料前處理

**1. 清理與標準化**（實際結果：2,213 → 2,207 項）
- 長表格（一列＝一食材的一項分析）轉成寬表格（一列＝一食材）
- 數值統一取「每100克含量」，單位統一為 kcal / g / mg / μg；熱量採「修正熱量」
- **結構性缺值補 0**：食藥署不會去驗「肉的膳食纖維」「蔬菜的維生素 B12」，這不是不知道而是天然為 0 → 纖維補 0 共 636 筆、B12 補 0 共 748 筆
- **單純型食品**（油、糖、飲料、調味料）：有熱量值時，未驗的蛋白質/脂肪/碳水視為 0。若不這樣做，大豆油、橄欖油、可樂、珍珠奶茶等 89 項常見食品都會被誤刪
- 熱量/蛋白質/脂肪/碳水任一仍缺 → 剔除 5 項（果凍、愛玉凍、啤酒等）
- 缺值超過 50% → 剔除 1 項
- 維生素 D、K（覆蓋率 13.5%）、總糖（54.8%）資料太少，保留欄位但**不做缺口評估**，避免把「沒驗」誤判成「沒吃到」

**2. 分類標籤**
- 食藥署 18 類 → 主食 397／蛋白質 709／蔬菜 379／水果 242／乳品 83／油脂與堅果 97／其他 300
- 名稱關鍵字細分：紅豆、綠豆、南瓜歸主食；地瓜葉、綠豆芽維持蔬菜；包子、水餃、粽子歸主食；香腸、火腿歸蛋白質；調味料（魚露、豆瓣醬）不會被誤分
- 每筆都記錄判定依據（`group_rule` 欄）
- 營養特徵標籤：高蛋白、高纖、低脂、高鈉；衍生特徵：三大營養素熱量占比、每 100 kcal 蛋白質

**3. Mapping 表**
- `data/reference/meal_mapping.csv`：13 道常見餐點 → 組成食材 + 克數 + **指定整合編號**
- 自動比對在真實資料上錯很多（例：「雞蛋」對到「雞蛋麵」、「麵條」對到「乾麵條」、「大豆油」對到「毛豆莢」），所以 51 個組成食材全部人工指定到正確的官方整合編號
- 這是報告的好素材：說明為什麼 Mapping 需要「自動比對 + 人工確認」兩階段

### 三、缺口計算與推薦
1. **每日需求**：熱量＝基礎代謝（Mifflin-St Jeor，用身高體重年齡）× DRIs 活動係數，並列出 DRIs 表參考值對照（`config.py` 的 `ENERGY_METHOD` 可改成直接查表）；其餘營養素查 DRIs 第八版
2. **缺口**＝每日需求 − 今日已攝取
3. **下一餐應補量**＝缺口 × 本餐占剩餘餐次比例（早 25／午 35／晚 30／點心 10%）
4. **推薦分數**＝各營養素補足率加權平均（今天越缺權重越高）− 熱量超出本餐額度扣分 − 鈉超過 DRIs 上限 2,300 mg 扣分
5. 每個推薦附理由，例：「維生素C 補足 100%；菸鹼素 補足 100%」

## 還需要你們做的事
1. `meal_mapping.csv` 的**價格與克數是示範估計值**，換成合作店家的實際菜單與份量
2. 看一下 `group_needs_review.csv`（65 項加工食品）要不要手動歸類
3. 報告中台師大資料的描述改為「提供六大類每日份數，作為均衡飲食判斷規則」

## 研究限制（可寫進報告）
- 食藥署多為生食材數據，餐點克數以可食生重估計；烹調調味（鹽、醬油）只在部分餐點估入，鈉可能低估
- 資料庫無水煮鮪魚罐頭、熟糙米飯，分別以鮪魚肉、生糙米（80 g ≈ 熟飯 200 g）近似
- 混合料理只歸入一個類別
- 「蛋 1 個＝55 g」、高蛋白與高鈉門檻為本專案自訂
- Mifflin-St Jeor 公式源自歐美族群，故同時呈現 DRIs 表值對照
